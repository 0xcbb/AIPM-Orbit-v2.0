# V2.0 已知问题

- 当前 V2 从 V1.2 并行分支起步，正式发布前必须合入或重放最终 V1.3 RC。
- 私人曲目队列和连续播放已实现，但尚未用真实 WebDAV / AList 账号完成端到端验证，当前结论为 **待人工确认**。
- iOS Keychain 实现需要在 macOS / Xcode 环境补齐和验证；当前 Windows 开发环境只实现 Android Keystore。
- 不同 WebDAV 服务对路径编码和属性响应存在差异，需用至少一个标准 WebDAV 和一个 AList 实例做真机兼容性验证。
- WebDAV 当前只扫描一个目录层级；SMB 已支持最多 8 层 / 2000 个资源的递归扫描。
- SMB 尚未使用真实群晖 / NAS 账号完成端到端 L3；进度拖动、网络切换、后台 30 分钟和蓝牙切歌结论为 **待人工确认**。
- 内嵌 ID3 / Vorbis 标签和受保护封面读取尚未实现。
- `dart_smb2` 为 BSD-3-Clause，底层 `libsmb2.so` 为 LGPL-2.1-or-later；开发包已记录第三方许可，商业发布前的动态链接、源码 / relinking offer 和商店披露合规性为 **待人工确认**。
