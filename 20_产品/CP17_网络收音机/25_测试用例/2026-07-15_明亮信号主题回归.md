# 2026-07-15 明亮信号主题回归

## 目标

在不改变 Void Radio 首页布局和播放行为的前提下，新增一套比现有暗色主题更明亮、控件边界更清晰的“明亮信号 / Luminous Signal”主题。

## 验收范围

- 主题选择器出现 `Luminous Signal`，切换后首页即时更新。
- 暖金石墨继续作为首次安装默认主题，已有用户主题偏好不被覆盖。
- 页面背景、主频率卡、快捷按钮、调谐模块、推荐频道和底部播放控制形成清楚的三层表面关系。
- 非激活功能图标与背景有明确明度差；激活态使用天青信号色，不依赖颜色以外的单一反馈。
- 地图保持低饱和底图，定位、marker、分段激活态与播放按钮使用主题信号色。
- 竖屏首页完整显示调谐、推荐频道和播放区；横屏无重叠和 overflow。
- 主题选择写入本地偏好，强停重启后保持。
- 推荐频道优先显示远程台标，台标容器尺寸和圆角保持一致；HTTP artwork 只在升级为 HTTPS 后尝试。
- 台标为空、协议不支持或加载失败时显示稳定的电台首字符，不出现破图、布局跳动或无限 loading。
- 不在 APK 内打包第三方电台官方 Logo。

## 自动化结果

- `dart format`：通过。
- `flutter test --no-pub`：63 / 63 通过，其中台标 URL、HTTPS 升级、首字符 fallback 和固定尺寸 Widget 回归 6 / 6 通过。
- `flutter analyze --no-pub`：ASCII junction 下通过，0 issue。
- `flutter build apk --debug --no-pub`：F 盘 ASCII 物理副本与独立 Pub Cache 下通过。

- 竖屏首页中主卡、快捷按钮、调谐区、推荐频道和播放控制形成清晰表面层级。
- 地图保持明亮低饱和瓦片，蓝灰抽屉、天青 marker / 播放动作和搜索控件可辨识。
- 横屏首页无重叠或 overflow。
