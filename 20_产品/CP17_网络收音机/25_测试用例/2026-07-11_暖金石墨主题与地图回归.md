# 2026-07-11 暖金石墨主题与地图回归

## 目标

新增“暖金石墨 / Warm Gold Graphite”主题并设为首次安装默认，保持页面布局不变，验证首页、主题选择器和地图页的暖炭墨 + 香槟金视觉一致性。

## 验收范围

- 首次无主题偏好时默认选择暖金石墨。
- 已持久化的用户主题选择在升级时继续保留。
- 首页主卡、快捷按钮、调谐区、预设频道和播放控制使用统一暖金强调。
- 地图瓦片使用暗暖石墨滤色，不回退为彩色旅游地图或棕黄色地图。
- 地图来源只在标题副标题中轻量显示，不出现遮挡地图的全宽来源条；抽屉、搜索、分段控制和电台卡保持暗炭墨表面。
- 定位按钮、播放动作和普通/选中 marker 使用香槟金。
- 点击 marker 后出现暗色选中卡，对应电台置顶并在抽屉中高亮。

## 自动化结果

- `flutter test --no-pub`：38 项全部通过。
- `flutter analyze --no-pub`：No issues found。
- debug APK 构建成功并覆盖安装到 moto G55 普通空间。

## 真机结果

- 主题选择器出现 `Warm Gold Graphite`，切换后立即生效并在 APK 覆盖升级后保持。
- 首页配色、边界和文字对比度正常，无新增布局变化。
- 中国地图瓦片保持可读，暖度克制，主色仍为中性炭黑。
- 普通 marker 为低亮金环，选中 marker 为高亮金色脉冲。
- 点击“广东珠江经济台”后，选中卡正常显示，抽屉对应电台置顶并高亮。
- 测试结束后恢复系统自动旋转：`accelerometer_rotation=1`。
- 2026-07-15 moto G55 补充回归：竖屏、横屏均已移除“© 高德地图 · 中国灰度 Web 瓦片”全宽悬浮栏，标题副标题仍保留 `中国灰度地图 / 高德 Web` 来源信息。
