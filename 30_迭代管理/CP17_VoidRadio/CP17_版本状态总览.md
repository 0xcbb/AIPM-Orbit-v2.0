# CP17 Void Radio 版本状态总览

## 一、结论

截至 2026-07-14，Void Radio 已有一个冻结的 Android 发布候选、两个可安装开发版本，但尚无任何版本完成正式商店发布。

- V1.1.3 RC2：唯一冻结的发布候选，可进入签名 AAB 和 Google Play 封闭测试准备。
- V1.2 dev：有独立分支、APK 和部分真机证据，但地图与回流门禁未全部完成。
- V1.3：尚未作为独立版本建立，不能视为已经开发。
- V2.0 dev：私人微电台主体已实现，当前是开发验证包，不是发布候选。
- V1.1、V1.1.1、V1.1.2 属于已被 V1.1.3 吸收的内部迭代，不建议再逐个发布。

## 三、尚未完成的工作

### 发布基础

- 创建并异地备份 Android upload keystore。
- 生成正式签名 `.aab`，复核 package name、versionCode、Target API 和前台媒体服务声明。
- 完成 Play Console 的 Data Safety、内容分级、广告、权限、版权来源和测试轨道配置。
- 按账号实际门槛完成 Google Play 封闭测试。
- 在 Mac、Xcode、iPhone 和 TestFlight 环境建立 iOS 构建与真机测试链路。

### V1.2 收口

- 真机验证地图聚合点点击缩放、地球背面完整流程和海洋兜底。
- 验证地图弱网恢复与长时间瓦片缩放稳定性。
- 在线 HTTPS 落地页复测试听与 App 回流。
- upload keystore 和 iOS Team ID 确定后配置 Android App Links / iOS Universal Links。

### V1.3 决策

- 决定是否需要把横屏仪器、原生投送、车载简洁交互和长期稳定性单独发布为 V1.3。
- 若保留，必须建立版本目标、分支、验收门禁、APK 和 RC；若不保留，应把必要能力拆入 V1.2.x 或 V2.0。

### V2.0 收口

- 使用真实标准 WebDAV、AList WebDAV 和群晖 / QNAP SMB2/3 账号完成保存重启、扫描、点播与删除。
- 验证 SMB 进度拖动、断线恢复、Wi-Fi / 移动网络切换、后台 30 分钟和蓝牙切歌。
- 补齐 iOS Keychain 与 iOS 私人存储播放链路。
- 评估并实现 ID3 / Vorbis 内嵌标签和受保护封面读取。
- 完成 `libsmb2` LGPL-2.1-or-later 商业发布合规方案。
- 将 V2 提交重放或合入最终稳定公开基线，解决当前从 V1.2 dev 并行开发形成的版本依赖。

### 尚未进入完成版本的能力

- 录音、回放和音频剪辑尚未实现，只保留为未来 Premium 方向。
- Android Auto / CarPlay 尚未实现；现有媒体会话只能作为后续车载接入基础。
- 手机本地目录私人微电台尚未实现，V2 当前覆盖 WebDAV、AList 与 SMB NAS。
- iOS 正式构建、Keychain、后台媒体、AirPlay、TestFlight 和 App Store 流程尚未建立。
- 账号、跨设备云同步、社区动态和自建内容后端不在当前路线内。

## 四、建议执行顺序

1. 不继续扩展新功能，先把 V1.1.3 RC2 做成签名 AAB并进入封闭测试。
2. 并行完成 V1.2 的地图、地球背面与回流剩余门禁，冻结 V1.2 RC。
3. 对 V1.3 做一次保留 / 取消决策，不让它继续成为模糊的中间版本。
4. 准备一个真实群晖或测试 SMB/WebDAV 环境，完成 V2 私人微电台端到端验证。
5. V2 合规与稳定基线完成后再创建 `v2.0.0-rc.1`，当前 `2.0.0+202` 继续标记为开发包。
