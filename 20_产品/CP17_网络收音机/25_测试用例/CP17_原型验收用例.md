# CP17 原型验收用例

## 版本回归总规则

- 后续任意新版本、热修、APK 打包、UI 调整、音频链路修改、地图/Radio-Browser 数据改动，都必须先按 [[CP17_版本回归测试规则]] 执行对应等级回归。
- 当前宿主机交付给用户体验的 APK 至少完成 L0 安全回归（`qa/run-cp17-safe-regression.ps1`）和已有截图/真机证据的 L2 人工复核；L1 API35 compact 模拟器 smoke 仅在明确接受 QEMU 风险时执行。Android 16 真机到位后，发布候选包必须补齐 L3 真机回归。
- 每次回归必须保留首页、床头钟、国家切换地图、地图默认态、地图抽屉展开态、地图点播回主页截图和 summary；不能只写“已通过”。
- 地图点播回主页后不得出现 `READY / 已接入 · 点击播放 / 已暂停`；必须是 `连接直播流`、`缓冲直播流`、`LIVE 直播中` 或明确 `播放失败`。
- 自动化通过后仍需人工看截图；如果截图和脚本结论冲突，以截图和产品状态为准，必须修脚本或修产品。

## 主界面验收

- 打开原型后，首屏必须直接进入收音机控制台，不出现营销介绍页。
- 频率 `100.3`、`FM`、电台名 `UFM 100.3` 必须形成清晰视觉层级。
- 主屏不得绘制模拟系统状态栏；时间、信号、耳机模式、电量等应由系统原生状态栏负责，页面只保留安全区顶部留白。
- 主屏顶部应在“选项”同一行左侧显示当前电台地区；默认 `UFM 100.3` 必须显示 `新加坡`，长地区名称应单行截断，不得与“选项”或主频率区重叠。
- 点击主屏顶部左侧地区文本，应弹出“切换国家”列表；列表国家名必须为中文，至少包含中国、新加坡、美国、英国、澳大利亚、日本、中国台湾、德国、法国、加拿大。
- 主频率区应具备精致仪器感：暗色声场、细密波形、调谐圆环与红色指针可见，但不得遮挡频率数字或变成高饱和营销渐变。
- 主屏应在电台名附近显示一行当前曲目 / 当前节目名，必须单行截断，不能压过频率数字和电台名，也不能包在半悬浮胶囊或工具条里。
- 点击当前曲目 / 当前节目名应打开通用 Now Playing 二级层：显示电台名、地区、当前曲目、封面占位和播放控制。该层不得替代首页仪表盘；上一首 / 下一首触发切台后应回到首页并刷新当前电台，避免沉浸层显示旧信息。
- 当真实 ICY 当前曲目能解析为“歌手 - 歌名”并匹配到歌词时，主屏可在曲目下方展示一行低噪音歌词预览；预览不得常驻占用大块空间，不得挤压主频率区、快捷按钮或底部快切轨。
- 点击歌词预览应打开同一个暗色 Now Playing 层：显示电台名、曲目、歌手、滚动歌词和 `-0.5 / +0.5` 本地校准；点击歌词行可按该行校准。歌词缺失、歌词服务失败或当前为 DJ/广告时，不得阻断播放，也不得把默认兜底文案误查成歌词。
- 关闭选项面板中的“开源歌词 Beta”后，主屏不得展示歌词预览，Now Playing 不得请求 LRCLIB；重新开启后可恢复轻量歌词。
- 主屏允许常驻展示收藏、喜欢、设置、隔空播放、附近电台五个低噪音快捷图标；不得常驻展示高级版入口、机械刻度盘、音量条、分享入口或底部 dock。
- 主屏快捷图标必须以独立浮雕圆钮成组排列，不得包裹在整条工具栏、玻璃底板或多组工具栏中，也不得散落在四角。
- 主屏必须提供精选电台快切轨，点击任一电台后无需进入调谐设置即可切换主频率、电台名、地区和播放源。
- 从地图页点播过的 Radio-Browser 电台必须加入首页快切轨，重启 App 后仍可见；出厂精选电台不得因持久化而重复出现。
- 收藏和喜欢必须按电台保存，切换到不同电台时图标状态应跟随电台变化；底部快切轨可用轻量小图标提示已收藏 / 已喜欢。
- 主屏精选电台应覆盖高质量启动包，至少包含 UFM 100.3、Radio Paradise、FluxFM Chillhop、KEXP、NTS Radio 和 ABC Double J；任何默认精选频道都必须在发布前通过源健康脚本首包探测，不能保留当前网络下不可播放的坏源。
- 主题色必须限制在策展主题内切换，不开放自由调色；当前至少提供“经典仪器”和“象牙白信号”。任一主题都必须保持高级、克制、低饱和，不得出现大面积营销渐变、装饰光球、单一紫蓝主题或高饱和娱乐化配色。
- 所有 icon-only 控件必须有 `title` 或 `aria-label`。

## 调频交互验收

- 从“选项”进入“调谐设置”后，拖动刻度盘时，中心红色指针固定，刻度尺移动。
- 频率值必须以 0.1 为单位更新，范围限制在 `87.5` 到 `108.0`。
- 鼠标滚轮与键盘左右键可以改变频率。
- 调到 mock 电台附近时，电台名称和元数据应随当前频率联动。
- 默认主界面不应显示刻度盘；刻度盘只在调谐设置面板中出现。

## 面板交互验收

- 点击“选项”可打开选项面板，关闭按钮和遮罩点击均可关闭。
- 选项面板在 720x1600 小屏上必须可滚动或完整露出所有入口；床头钟、睡眠定时、声音明信片不得被底部截断。
- 选项面板每个可点击行必须有稳定语义标签，便于辅助功能和 ADB smoke 通过功能名定位入口。
- 点击播放按钮可切换播放/暂停图标。
- 点击电台列表中的电台可跳频到对应频率。
- 收藏状态在选项面板和电台列表中必须可见。
- 主屏收藏与喜欢图标必须有选中态反馈，点击后图标状态应切换。
- 收藏 / 喜欢状态必须本地持久化，重启 App 后仍保留对应电台状态。
- 选项面板必须提供“首页电台库”入口；进入后应能拖拽排序、移除首页电台、手动添加 http/https stream URL。
- 选项面板必须提供“全球搜索”入口；搜索关键词应能按电台名、地区/state、tag 查询 Radio-Browser，并可直接加入首页播放。
- 选项面板必须提供“导入播放列表”入口；粘贴 M3U、JSON 或 URL 集合后，应把有效 http/https 电台导入首页电台库，并跳过无效行。
- 选项面板必须提供“睡眠定时”入口；选择 15/30/60 分钟后，应到时暂停播放；选择关闭定时应取消既有计时器。
- 选项面板必须提供“开源歌词 Beta”开关；该开关必须本地持久化，关闭后不得影响播放、切台和 Now Playing 基础信息。
- 选项面板必须提供“外观 / 主题色”入口；切换“经典仪器 / 象牙白信号”后，首页背景、主强调色、调谐条、选中态和设置控件应同步变化，强停重启后保持上次主题。
- 移除出厂精选电台后，重启 App 不得自动恢复该电台；至少应保留一个首页电台，不能删到空列表。
- 手动添加 URL 时，名称为空应使用 URL host 作为兜底名称；无效 URL 应给出轻量错误提示，不得写入首页电台库。
- 首页电台库中的每个电台应提供低干扰管理入口，可标记 / 恢复主源、添加备用流、移出首页。
- 标记主源不可用后，该电台行应显示轻量“主源已避开”状态；添加备用流后应显示“备用 N”状态。
- 备用流 URL 必须校验为有效 http/https 地址；无效地址不得写入本地库。
- 主屏不出现底部 dock，不显示长 URL 或长文字 chip。
- 待机主题面板选择任一待机主题后，应进入待机模式；外观主题切换不得误触发待机模式。

## 真实直播流验收

- 默认不应自动播放直播流；必须由用户点击播放按钮触发 `<audio>` 播放。
- 已配置 `streamUrl` 的电台应显示轻量播放状态：已接入、连接中、直播中、暂停或播放失败。
- 已配置当前曲目的 mock 电台应在主屏显示 `nowPlaying`；连接中时可显示“曲目识别中”，无元数据时不得用空白占位。
- 播放状态进入 `LIVE 直播中` 后，支持 ICY metadata 的精选电台应显示真实曲目或保持“正在获取曲目信息 / 直播节目”等中性文案；不得再使用本地假歌名轮播或模拟节目单作为真实曲目。
- 切换到另一个已配置 `streamUrl` 的电台时，播放器应换源；如果原本正在播放，应尝试继续播放新电台。
- 没有 `streamUrl` 或流地址失败时，主屏不得显示“LIVE 直播中”。
- 某电台主源被本地标记不可用且存在备用流时，点击播放应优先使用备用流，不应继续请求已标记坏源。
- 某电台所有候选流都被本地标记不可用时，点击播放应给出轻量提示，不得假装进入直播状态。
- 播放器收到带 `fallbackUrls` 的媒体项后，播放失败时应继续尝试后续备用流候选。
- 播放过程中流报错时，应继续尝试同一电台后续备用流候选，不得只停在 error 状态。
- 直播流完成、远端断开或候选耗尽后，UI 必须保持明确失败或候选切换提示，不能被播放器后续 idle/ready 事件覆盖成“已接入 · 点击播放”。
- 自动尝试备用流或下一候选源时，主屏必须显示轻量状态提示或浮动 SnackBar，不能无感串台。
- 切台和备用流重试过程中允许出现 1 秒左右低音量“虚空寻台”底噪；真实电台 ready、暂停、停止或失败后必须停止，不得变成循环背景音，不得影响播放/暂停按钮和锁屏媒体状态。
- 流地址必须优先使用 HTTPS；如果只有 HTTP 流，需在正式版前替换或提供兼容策略。
- 从 Radio-Browser 选择的远程电台必须能成为当前播放电台；如果没有 FM 频率，主频率区应显示 `LIVE / NET`，不能伪造一个频率。

## 附近电台地图验收

- 从“选项”点击“附近电台”后，应进入全屏地图页，不应把地图内容塞入主屏。
- 地图页应尝试读取用户定位；定位授权成功时应按本机经纬度居中地图、尝试反查城市/国家码，并优先用 `geo_lat / geo_long / geo_distance` 查询附近电台；附近结果不足时应补当前城市/国家目录。授权失败或超时时展示默认城市并保持可用，同时允许用户手动切换国家和城市。
- 从“附近电台”入口进入地图页时应自动尝试真机定位；从主屏国家入口进入地图页时应尊重用户手动选择，不得自动覆盖目标国家。
- 地图 provider 必须通过抽象层选择；V1 中国大陆 provider 使用高德 Web 灰度瓦片兜底并保持地图不空白，面向用户和商店截图不得出现 `SDK Key 待接入`、`Key pending` 等半成品文案。
- 地图页应优先用当前选择范围查询 Radio-Browser：国家“全部”使用 `countrycode`，城市/地区使用 `countrycode + state/region`；筛选 `lastcheckok=1`、有 `url_resolved` 或 `url` 且 codec 不是 `UNKNOWN` 的电台；地区结果不足或为空时必须自动补国家级结果；接口失败、无结果或离线缓存为空时必须回退到本地精选电台。
- 国家切换弹窗应优先同步 Radio-Browser `/json/countries`，并以中文国家/地区名展示；搜索“中国 / JP / 美国 / Singapore”等关键词时应过滤国家列表，公共目录不可用时仍保留内置重点国家。
- Radio-Browser 结果应使用 `stationuuid` 作为唯一键，优先播放 `url_resolved`，并展示轻量来源状态（Radio-Browser / 缓存目录 / 本地精选）。
- Radio-Browser 查询结果应本地缓存约 24 小时，重复进入地图页不应依赖每次实时请求成功。
- 地图页必须显示城市名、定位状态、地图背景和少量 marker；手动国家/城市切换、分类筛选、附近电台列表和当前选中电台卡必须收进单一底部抽屉，不得在地图上同时堆叠多个浮层卡片。
- 地图页底部抽屉必须支持上滑展开为接近全屏的目录模式；默认状态应保留地图空间感，当前 Flutter 目标约为 38% 屏幕高度；展开状态应能容纳搜索框和多条电台结果，第一条电台不得被顶部搜索/筛选区域遮挡，用户不应被迫在小窗口内低效找台。
- 地图页底部抽屉展开态应采用精致目录密度：搜索框、快捷筛选和电台列表不应显得拥挤或过粗；底部不得常驻重复的“上滑展开”说明文案。
- 切换国家或城市后，地图瓦片、目录请求、地图标记、附近电台快选和当前选中电台卡必须同步变化。
- 底部抽屉必须提供“电台 / 位置”两种状态；默认展示电台列表，切到“位置”后才展示国家/城市选择。
- 位置页必须先展示当前国家的“全部电台”和重点城市/地区，再展示 Radio-Browser `/json/states/<country>/` 返回的地区/州/城市目录，最后展示国家切换列表；切换城市/地区时应使用 Radio-Browser `state` 字段查询，并移动地图中心。
- 位置页必须提供独立“搜索城市 / 州 / 地区”输入框；输入关键词时应过滤内置重点城市，并请求 Radio-Browser `/json/states/<country>/<filter>`；搜索激活时不得把“全部电台”等无关入口排在匹配城市前面。
- Radio-Browser 国家级查询结果不应只展示少数几条；抽屉应至少默认展示 12 条，并提供“加载更多”逐步展开当前页结果，当前页用尽后必须通过 `offset` 继续同步下一页。
- 地图页电台搜索框应支持按电台名、标签或地区关键词查询 Radio-Browser；搜索结果为空时展示轻量空状态，不得回退混入无关热门电台。
- 地图页电台搜索应同时尝试电台名、tag 和地区/state；快捷筛选 chip 至少包含 `jazz`、`news`、`classical`、`electronic`、`talk`、`pop`。
- 地图页电台列表默认只能显示“播放”等动作入口；用户未点击前，不得把第一条或任一远端结果误标为“播放中”。
- 从主屏地区入口选择任一国家后，应进入地图页对应国家“全部”目录；地图标题、抽屉标题、国家标签和电台集合必须同步变化，不能只改变标题不改变列表。
- 点击重新定位后，应退出手动城市选择，重新请求真机/浏览器定位；Android APK 首次使用时应触发系统定位权限请求。
- 类型 / 情绪分段和筛选 chip 必须可点击，筛选后电台卡与地图标记选择状态应同步。
- 点击地图电台列表中的任一电台行，应直接触发播放、关闭地图页，并在主屏显示该电台名称与 `LIVE 直播中` 或明确失败状态；不能回到主屏后仍保持暂停并要求用户再次点击播放。
- 点击地图电台列表中的可播放电台后，主屏至少应立即进入 `连接中 / 连接直播流` 状态；若流可用，应进入 `LIVE 直播中`，若流不可用，应进入明确失败提示，不能静默停留在 `READY / 已接入 · 点击播放`。
- 地图页点播的 Radio-Browser 电台必须被加入本地首页电台库，并在首页底部快切轨中可直接再次播放。
- Radio-Browser 流地址播放失败时，若当前列表还有其它带 `streamUrl` 的候选，应自动尝试下一条；所有候选失败后才显示明确失败 / 点击播放状态。
- 尝试备用流或播放失败时，主屏必须有轻量可见提示，不能静默停留或无感串台。
- 点击地图 marker 后，当前选中卡和地图标记必须同步更新；点击选中卡的“收听”后，主屏频率和电台名应切换到对应电台并关闭地图页。
- 地图页必须提供返回按钮和重新定位按钮，所有 icon-only 控件必须有 `title` 或 `aria-label`。
- 地图瓦片必须有兜底策略；CARTO / OSM provider 任一短时失败时，地图页不得出现整屏空白或阻断电台目录操作；瓦片加载中的海面/兜底区域可以存在轻微色块边界，但不能遮挡 marker、标题、抽屉或播放操作。
- 后续如接入瓦片缓存，必须通过 `Cp17MapProvider` / TileProvider 层实现并验收缓存命中、fallback、错误瓦片回收和缩放拖拽流畅度；不得用普通图片缓存替代地图瓦片层。

## 声音明信片分享验收

- 正式 Flutter App 点击分享按钮后，应生成专用 `PostcardWidget` 明信片，不得直接截取整屏。
- 明信片必须是 `SIGNAL INTERCEPTED` 信号截获回执风格：白底热敏票据、旧纸白背景、褪色墨水灰、唯一红色信号点、虚线走纸、纸张噪点、静态波形、数据区等宽字体和中文旁白衬线体；不得退回浅色风景卡、普通音乐卡、主屏仪器卡截图或黑底服务器日志风。内容必须包含频率/NET、电台名、当前曲目、城市/坐标、UTC 时间戳、协议/码率估算、距离或直播流兜底信息。
- 明信片截图必须通过 `RepaintBoundary.toImage(pixelRatio: 3.0)` 生成高清 PNG，并保存到 `getTemporaryDirectory()`。
- 保存完成后必须调用系统分享面板，优先使用 `SharePlus.instance.share(ShareParams(...))` 分享图片和短文案。
- 分享短文案和明信片底部 note 必须带 Void Radio 内置情绪短句，且同一次分享重绘时保持稳定；可出现“我的深夜，你的清晨。”、“世界另一侧的日常，刚好穿过我的房间。”等克制表达，不得退回普通促销话术。
- Android 测试 APK 默认必须通过 `--dart-define=CP17_LISTEN_BASE_URL=https://listen.feedar.cc/` 打包；微信/WhatsApp 分享文案应包含可点击的 `listen.feedar.cc` 落地页链接，而不只是 PNG 图片。
- 真机验收需覆盖微信、WhatsApp、AirDrop / 系统分享目标；失败时应给出轻量错误反馈，不得阻断播放。
- Flutter 主工程的“声音明信片”入口必须实际调起系统分享，不得停留在“待迁移”占位文案。

## 待机模式验收

- 待机模式必须显示时钟主体、当前频率、电台名和音频动势。
- 翻页钟、辉光管、8-bit、仪表盘主题必须能切换。
- 宽屏/横屏小高度视口下应自动呈现待机模式。
- 待机模式必须提供返回主控制台和主题切换入口。

## Flutter 原生音频内核验收

- 安装给用户体验的 Flutter APK 必须是 `cp17-flutter-v1-ui-audio-debug.apk`，不得误交付仅显示 `CP17 AUDIO CORE` 的音频测试壳。
- 含 Flutter Radio-Browser 地图、城市/地区发现、本地首页电台库管理、坏源标记、备用流、全球搜索、播放列表导入、睡眠定时和声音明信片能力的体验 APK 必须优先使用 `cp17-flutter-v1-v1_1-country-map-playback-standby-smoke-debug.apk`；`nearby-city-search` 和 `country-map-playback-smoke` 为同内容留档别名；旧的 `cp17-flutter-v1-v1_1-complete-debug.apk` 代表 V1/V1.1 首轮完整包，`cp17-flutter-v1-source-recovery-debug.apk` 只代表坏源与备用流阶段。
- Flutter 首页必须恢复 CP17 产品主界面：地区、选项、深色频率仪表盘、当前曲目、五个快捷按钮、精选电台快切轨和播放控件必须同时可见。
- 默认首页必须显示 `新加坡 / 100.3 FM / UFM 100.3`。
- 首页点击播放后必须能进入 `LIVE 直播中` 或明确失败状态，不能停留在工程测试状态。
- Flutter 音频内核工程必须使用 `audio_service + just_audio + audio_session`，不得用 `just_audio_background` 替代主架构。
- `AudioHandler` 必须封装播放器，UI 不得直接持有或操作 `AudioPlayer`。
- `AudioService.init` 必须在 `runApp` 前完成。
- Android 包名必须为 `com.aipm.cp17.radio`。
- Android manifest 必须包含 `INTERNET`、`WAKE_LOCK`、`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_MEDIA_PLAYBACK`，并声明 `AudioService` 与 `MediaButtonReceiver`。
- 点击播放后，状态必须从 `READY / CONNECTING / BUFFERING` 进入 `LIVE`，失败时进入明确 `ERROR`。
- 播放中必须优先读取 ICY Metadata 并更新当前曲目；无元数据时显示兜底直播文案，不得显示空白。
- 歌词服务必须只由真实 ICY 当前曲目触发，至少覆盖 LRC 时间轴解析、制作信息过滤、纯文本歌词兜底和歌词服务失败兜底；“开源歌词 Beta”关闭时不得请求 LRCLIB；商业版歌词授权与 provider 合规性为 **待人工确认**。
- V2 私人微电台验收时，WebDAV / AList / NAS / 本地音乐库必须复用 Now Playing 层，并优先读取本地音频标签、同目录封面和同目录 `.lrc`；在线歌词只作为兜底，主界面仍保持收音机仪表盘。
- 退到后台后，Android media session 必须仍存在。
- 系统媒体键 Pause 必须把 media session 状态切到 `PAUSED`。
- 系统媒体键 Play 必须把 media session 状态切回 `PLAYING`。
- Headless AVD 不作为当前宿主机默认验收环境；即使在受控风险确认后使用，也只验证安装、启动、连流、状态和媒体会话。锁屏界面、通知栏样式、蓝牙耳机按钮和真实音质必须在 Android 16 真机复测。

- Flutter 合体包必须通过地图 provider 测试：中国大陆 provider 路由与海外 provider 路由保持明确区分，海外 CARTO / OSM provider 具备 fallback URL。
- Flutter 合体包必须通过 Radio-Browser 地区和附近查询测试：filtered state search 应命中 `/json/states/<country>/<filter>`；nearby search 应携带 `geo_lat`、`geo_long`、`geo_distance` 参数。

- 点击聚合点只放大地图，不直接播放；点击单台 marker 后对应电台必须进入下方列表首位并显示显式播放入口。
- 当前地区预设第一项必须是当前电台，同地区收藏优先于普通地区候选；调谐尺仍保持频率顺序，不跟随收藏排序。
- 收藏超过首页可见数量时，设置中的收藏电台页必须展示全部收藏并支持搜索；当前电台优先显示，点击条目切台，取消收藏后条目移除但电台源仍保留在电台库。
- `voidradio://listen` 只接受 `voidradio` scheme、`listen` host 和 HTTPS 主流地址；HTTP 或畸形链接必须拒绝。
- 外部分享链接打开 App 后只能导入并选中电台，播放状态保持暂停，用户点击播放后才能联网收听。

### V2.0 私人微电台

- 设置 -> 收听必须存在“私人微电台”入口，进入后可添加 NAS SMB、WebDAV / AList WebDAV 连接；没有真实实现时不得保留可点击占位入口。
- 从设置进入私人微电台后，点击返回按钮或使用系统侧滑返回必须恢复原设置面板及其当前位置，不能越级返回首页。
- 连接地址必须禁止内嵌账号密码和查询 Token；公网服务只允许 HTTPS，HTTP 只允许 localhost、`.local` 和 RFC1918 局域网地址；名称、地址、根目录和账号可以普通持久化，密码 / Token 不得出现在 SharedPreferences 明文。
- Android 凭据必须由 Keystore AES-GCM 加密；保存、读取和删除都必须覆盖，保险箱错误不得在 UI 或日志泄露凭据。
- 测试并保存必须实际发起带 `Depth: 1` 的 WebDAV `PROPFIND`；401 / 403 显示认证失败，超时显示网络错误，非 200 / 207 显示明确 HTTP 状态。
- XML multistatus 解析必须跳过当前目录自身，区分子目录、音频、`.lrc` 和封面；至少支持 MP3、AAC、M4A、FLAC、OGG、OPUS、WAV。
- 同名 `.lrc` 必须关联到对应曲目；`cover / folder / front` 图片可以作为目录封面候选。
- 扫描列表中的任意曲目都可明确点播；超过三首时必须有完整曲目列表，不能只让前三首可用。
- 点播后整个扫描结果进入现有后台媒体队列，通知栏 / 蓝牙上一曲下一曲和自然播完切歌必须更新到正确索引。
- 私人队列切歌后首页曲名、Now Playing 和本地 `.lrc` 必须同步；本地歌词缺失时才允许进入在线歌词兜底。
- `Authorization`、密码和 Token 不得进入 `PlaybackItem`、`MediaItem.extras`、普通电台快照、分享参数或测试输出。
- 私人曲目不能作为普通网络电台写入首页 StationLibrary；连接删除后必须同时删除 Keystore 中对应凭据。
- Android debug APK 构建、`flutter analyze` 和全量 `flutter test` 必须通过；真实 WebDAV 与 AList 实例、后台 30 分钟和蓝牙切歌属于 V2 真机门禁。
- SMB 地址必须使用 `smb://主机/共享名`，只允许局域网、`.local`、单标签 NAS 主机和 Tailscale `100.64.0.0/10`；非 445 端口和公网 SMB 必须拒绝。
- SMB 必须使用 SMB2/3，禁止 SMB1；“强制 SMB3 加密”开启时必须使用 SMB3、seal 和 signing，不能静默降级到未加密 SMB2。
- SMB 扫描必须能递归子目录，最多 8 层 / 2000 个资源；不同专辑的同名文件必须按父目录隔离歌词和封面关联。
- SMB 音频播放必须由仅监听 `127.0.0.1` 的 Range 网关提供，至少正确处理无 Range、`bytes=start-end`、开放结束和后缀 Range；非法或越界范围返回 416。
- 本机 Range URL 必须使用随机令牌，不得包含 NAS 地址、共享名、远端路径、账号或密码；切换回公共电台后必须关闭 SMB 会话和本机服务器。
- APK 必须包含 `arm64-v8a`、`armeabi-v7a`、`x86_64` 的 `libsmb2.so`，并记录 `dart_smb2` BSD-3-Clause / `libsmb2` LGPL 相关第三方许可。
- 在没有真实群晖 / NAS 账号完成扫描、点播、拖动进度、熄屏后台和蓝牙切歌前，SMB 只能标记为开发验证通过，不得标记 L3 或发布放行。
