# V2.0 私人微电台

## 目标

把用户自己的 WebDAV、AList WebDAV 和 NAS 音乐目录接入 Void Radio，并继续用 `NET · PRIVATE STATION` 的收音机表达完成连接、扫描、播放和 Now Playing，而不是变成文件管理器。

## 第一阶段范围

- 新建和管理 NAS SMB、WebDAV / AList WebDAV 连接。
- 使用 Android Keystore 加密保存密码或 Token；普通偏好只保存非秘密连接信息。
- 测试连接并以 WebDAV `PROPFIND Depth: 1` 扫描目录。
- 识别 MP3、AAC、M4A、FLAC、OGG、OPUS、WAV，以及同目录 `.lrc` 和常见封面。
- 在设置的“收听”分组提供私人微电台管理入口。
- 扫描结果支持完整曲目点播、后台队列、上一曲 / 下一曲和自然连播。
- 队列切歌同步首页、通知栏和现有 Now Playing；同目录 `.lrc` 优先显示。

## 后续阶段

- 音频内嵌标签和受保护封面进入现有 Now Playing。
- 本地目录接入和 NAS 能力扩展。

## 不做范围

- SMB / DLNA 自动发现。
- 录音、剪辑、云端转码、账户系统和服务器端音乐索引。
- 把首页改成文件列表或普通歌单播放器。

## 第一阶段验收标准

- 密码 / Token 不出现在 SharedPreferences 明文、媒体元数据、日志和分享参数中。
- 可连接标准 WebDAV 和 AList WebDAV，并清晰反馈认证、网络、协议和空目录错误。
- 扫描结果正确区分目录、音频、歌词和封面，同名歌词 / 封面可关联到音频。
- 保存连接后重启 App 仍可读取非秘密配置，并从 Android Keystore 恢复凭据。
- 任意扫描曲目可播放，通知栏 / 蓝牙上一曲下一曲与首页当前曲目保持同步。
- 同目录 `.lrc` 优先于在线歌词，并按当前播放位置校准。
- 群晖 / NAS SMB2/3 可递归扫描并通过本机 Range 网关播放；SMB1 和公网 445 不在支持范围。
- `flutter test`、`flutter analyze` 和 debug APK 构建通过。
