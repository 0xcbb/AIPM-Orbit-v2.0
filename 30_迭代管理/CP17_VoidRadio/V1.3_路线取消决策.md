# V1.3 独立版本取消决策

## 决策

取消 Void Radio V1.3 作为独立发布版本，不创建 `v1.3` 分支、tag、APK 或 RC。

## 原因

- 当前已存在 V1.1.3 RC2、V1.2 dev 和 V2.0 dev 三条版本线，继续插入 V1.3 会扩大合并和回归成本。
- 原计划中的横屏仪器、媒体会话和长期稳定性已有部分能力，适合作为 V1.2.x 持续收口，而不是单独占用一个版本。
- Android Auto / CarPlay 的平台接入与驾驶安全验收明显大于普通 UI 优化，不应为了填充 V1.3 而仓促混发。
- V2 私人微电台已经基于 V1.2 并行开发，直接以最终 V1.2 稳定基线承接 V2 更清晰。

## 去向

- 横屏布局、后台稳定性、媒体会话和 OEM 兼容修复：并入 V1.2.x。
- Android Auto / CarPlay：后移到 V2.1 或单独车载版本评估，不进入 V2.0 首发。
- V2.0 发布门禁：从“依赖未来 V1.3 RC”改为“重放到最终 V1.2 稳定基线”。
