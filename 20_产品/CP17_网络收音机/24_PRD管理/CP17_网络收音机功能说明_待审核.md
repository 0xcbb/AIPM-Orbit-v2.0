# CP17 网络收音机功能说明（待审核）

## 1. 文档目的

本文用于审核 CP17 网络收音机当前原型和下一阶段产品化范围，重点说明主界面、Radio-Browser 公共电台目录、地图发现、真实音频流测试、待机床头钟、Android APK 测试壳和后续正式版边界。

本文不等同于最终商业版 PRD。当前实现包括 React/Vite 高保真原型、Capacitor Android 测试壳，以及 Flutter V1 UI + 原生音频 + Radio-Browser 地图发现合体包。后台播放真机长测、锁屏控制、完整待机主题、系统分享和正式地图 provider 仍需后续产品化。

> 2026-07-11 状态修订：Flutter V1.1.2 已完成 moto G55 的 Home、锁屏、系统媒体键和快捷设置媒体卡真机回归；系统分享、地图定位、横竖屏缩放与抽屉点播已可用。仍未完成的是正式签名 AAB、Play Console 网页表单和更长时长/更多 OEM 机型回归；地图 provider 仍为 V1 的高德 Web / OSM 瓦片方案，不等同于正式商业 SDK。

## V1.1.2 发布硬化验收补充（2026-07-11）

- **播放源兼容：** 内置精选、独立信号、地图目录、语言信号、手工添加和播放列表导入统一接受 HTTPS 直链与 HLS，拒绝 HTTP、`.pls`、`.m3u`。覆盖升级时更新旧内置独立信号 URL，保留用户排序、收藏和当前选择。
- **独立信号可用性：** WFMU、NTS、BFF.fm、Kiosk Radio、Soho Radio、WPRB、WKDU、WFUV 等均使用已探测直链；Kiosk Radio 使用 `_b` 主源和 `_a` 备用源。发版探测为全部内置主备 `38/38`、独立信号 `22/22` 通过。
- **地图体验：** 中国地图使用高德灰度 Web 瓦片和 WGS84 -> GCJ-02 投影，海外使用 OSM DE/HOT 与 WGS84；瓦片平移缓冲、淡入和错误瓦片回收已启用。marker 具备语义标签，点击后出现锁定卡并将电台置顶到抽屉，用户确认“收听”后回首页播放。
- **定位与布局：** moto G55 已验证定位到福田区附近，marker 与地图对齐；竖屏、横屏、四向平移、双击缩放、抽屉展开/收起无 overflow。定位失败仍按既有规则回退国家目录，不阻断地图浏览。
- **后台与通知：** Android 13+ 首次播放请求通知权限；`audio_service` 前台服务在 Home 和熄屏后保持播放，系统媒体键及 Motorola 完整快捷设置媒体卡可暂停/恢复。
- **OEM 边界：** moto G55 划掉最近任务时，Motorola DeviceGuard 会主动 `forceStopPackage`，前台服务随之停止。该行为属于 OEM 系统策略，不作为本版代码阻塞；用户帮助中应建议锁定任务或关闭自动清理。
- **非目标：** 本轮不加入 NAS、录音、CarPlay / Android Auto，不以假 AirPlay/Cast 设备面板代替原生投送能力；半成品入口不进入发布包。

## 2. 产品定位

CP17 是一个高质感网络收音机应用，核心体验不是“堆很多频道”，而是把网络电台做成一台精密、安静、有实体仪器感的桌面设备。

对外品牌名统一为 `Void Radio`。CP17 继续作为内部产品编号、工程路径、包名和文档体系使用；APK 桌面名称、系统通知、分享文案、声音明信片和公网落地页展示 `Void Radio`，避免用户看到内部代号。

核心关键词：

- 网络电台：接入真实直播流，支持全球公共电台目录浏览。
- 精密仪器：主屏保留大频率、暗色表盘、动态声波、横向调谐条和克制控制。
- 桌面摆件：横屏或待机时呈现床头钟 / 翻页钟 / 仪表盘等主题。
- 零后端优先：默认精选、本地缓存、公共 API、手机本地渲染和系统能力优先。
- 少而精：首页保证稳定、有品味、打开即用；海量发现放入地图和目录页。

## 4. 用户场景

### 4.1 打开即听

用户打开 App 后，默认看到一个简洁、高质感的收音机主界面。首页不进入营销页，不展示复杂频道广场，而是直接提供精选电台、当前频率、播放按钮和少量常用操作。

目标体验：

- 第一次打开就能理解这是“收音机”。
- 不需要先选国家或注册账号。
- 默认电台质量高，减少坏源和广告感。

### 4.2 按国家/地区探索电台

用户点击主屏左上角地区文本，打开国家切换列表。国家列表来自 Radio-Browser 公共国家目录，并以中文国家/地区名展示。用户选择国家后进入地图发现页，看到该国家范围内的公共电台目录。

目标体验：

- 用户可以从中国、日本、美国、英国、新加坡等国家开始探索。
- 国家多时可搜索，例如输入 `日本`、`JP`、`美国`、`Singapore`。
- 选择国家后，地图、电台列表、标题、选中卡同步变化。

### 4.3 在地图页找附近或某地电台

地图页承载“附近电台”和“公共目录发现”。它不是复杂频道广场，而是一个地图背景 + 单一底部抽屉。

用户可以：

- 重新定位到本机所在位置。
- 切换国家。
- 切换城市/地区。
- 按类型或情绪筛选。
- 搜索电台名、标签或地区。
- 加载更多 Radio-Browser 电台。
- 点击电台后直接回到主页播放。

目标体验：

- 信息集中在底部抽屉，地图上不堆多个浮层。
- 默认保留地图空间感，抽屉可上滑到近全屏目录模式，并使用更精致、紧凑的目录密度方便大量浏览。
- 点击电台无需再到调谐设置里操作。
- 公共目录数量多时可持续加载，而不是只显示少数几条。

### 4.4 桌面床头钟

用户横屏放置手机，或在选项中手动进入待机主题，App 变成桌面摆件。待机模式不是纯时钟，仍保留当前电台、频率/NET 标识和音频动势。

目标体验：

- 适合工作桌、床头、咖啡馆、夜间收听。
- 翻页钟要有物理厚度和机械翻动质感。
- 音乐和时间形成一个安静、可长期看的界面。

### 4.5 车载模式

车载模式参考普通电台 App 的大控制区逻辑，但不复制其彩色播放器首页。它应是一个独立二级模式，面向驾驶场景：

- 大播放/暂停、上一台/下一台和收藏按钮。
- 当前电台、地区、曲目大字号显示。
- 不出现地图抽屉、国家筛选、搜索框和复杂调谐。
- 后续与 Android Auto / CarPlay、蓝牙方向盘按钮和语音入口一起验收。

V1/V1.1 暂不把车载模式混入普通首页，避免破坏 Void Radio 的安静仪器感。

## 5. 主界面功能说明

### 5.1 主屏信息层级

主屏固定展示：

- 当前电台地区：左上角，例如 `新加坡`。
- 选项入口：右上角。
- 主频率 / NET 标识：第一视觉中心，数字后方可显示随播放态轻微跳动的红紫动态声波。
- 电台名：频率下方。
- 当前曲目 / 当前节目名：电台名附近，自然文本呈现。
- 本地 / 信号源时间：在当前曲目附近以极小字号展示，例如 `LOCAL 02:14 | SIGNAL 14:14`。
- 播放状态：已接入、连接中、LIVE、暂停、失败。
- 快捷图标：收藏、喜欢、床头钟、隔空播放、附近电台。
- 精选电台快切轨。
- 播放控制：上一台、播放/暂停、下一台。

不应常驻展示：

- 大面积营销文案。
- 复杂底部 dock。
- 长 URL chip。
- 机械刻度盘。
- 大音量条。
- 多层浮动工具栏。

### 5.2 主屏快捷操作

| 操作 | 当前行为 |
|---|---|
| 点击播放 | 播放当前电台真实直播流 |
| 点击暂停 | 暂停 `<audio>` |
| 上一台 / 下一台 | 在首页精选电台中切换 |
| 精选电台轨 | 直接切换主电台 |
| 收藏 | 切换当前电台收藏状态，并保存到本地 |
| 喜欢 | 切换当前电台喜欢状态，并保存到本地 |
| 设置 | 打开调谐设置 |
| 隔空播放 | 打开隔空播放原型面板 |
| 附近电台 | 进入地图发现页 |
| 左上角地区 | 打开国家切换列表 |
| 选项 | 打开系统功能菜单 |

### 5.3 当前曲目

当前主屏已展示当前曲目/节目名。Flutter 合体包优先解析真实 ICY metadata；精选电台和无元数据公共流保留本地节目单或直播文案兜底：

- UFM / Radio Paradise 等支持元数据的流会动态更新当前曲目。
- 精选电台可用本地节目单作为原型兜底，避免首页空白；该兜底必须标记为非真实曲目，不触发 LRCLIB 歌词查询。
- Radio-Browser 公共电台无元数据时显示流信息或通用直播文案。
- 真实 ICY 曲目能解析为“歌手 - 歌名”时，才触发 LRCLIB 歌词查询；默认兜底文案不得用于查词。
- 用户可在选项面板关闭“开源歌词 Beta”，关闭后不再查询 LRCLIB，也不展示首页歌词预览。

正式版要求：

- 优先解析 ICY metadata。
- 对不提供 ICY 的电台，可接官方播放 API。
- 仍无法获取时显示明确的“直播节目”状态，不显示空白。
- 歌词 provider 合规性在商业上架前仍为 **待人工确认**，V1.1 只作为可关闭的 Beta 能力。

### 5.4 横屏首页

横屏首页不能把竖屏内容简单压扁。V1.1 Flutter 合体包在横屏且高度较小时使用分栏仪器布局：

- 顶部仍保留当前地区和选项入口。
- 左侧保留主频率 / `NET LIVE` 仪表卡。
- 右侧承载电台名、当前曲目、快捷按钮和低矮调谐槽。
- 底部保留电台快切轨，并把播放控制改为紧凑横向控制。
- 电台快切轨不得压住主频率卡，播放控制不得压住底部手势条。

该模式不是正式车载模式。车载模式后续应进一步放大主操作、减少信息密度，并与 Android Auto / CarPlay、蓝牙方向盘按钮一起验收。

## 6. 首页精选电台

首页精选电台是本地 seed data，不依赖 Radio-Browser 实时返回。这样做是为了保证打开 App 时稳定、有品味、可播放。

当前默认精选方向：

- 华语/本地化：UFM 100.3
- 专注/工作：FluxFM Chillhop
- 独立音乐：KEXP
- 前卫/地下：NTS Radio
- 发烧友/高品质：Radio Paradise
- 另类/澳洲：ABC Double J

所有出厂精选都必须带 `countryCode` 元数据，用于主屏左上角地区入口和地图国家目录路由。例如 UFM 100.3 为 `SG`，Radio Paradise / SomaFM / KEXP 为 `US`，NTS Radio 为 `GB`，ABC Double J 为 `AU`。

- 如果用户本地标记了坏源或添加了自定义备用流，仍按本地流健康管理优先级避开已标记 URL。

## 7. Radio-Browser 数据能力

### 7.1 数据源定位

Radio-Browser 是 CP17 的公共电台目录来源，用于地图发现、国家/地区浏览和后续搜索。它不替代首页精选。

数据策略：

- 首页：本地精选，保证品质和稳定。
- 地图/发现：Radio-Browser，提供全球目录。
- 公共目录失败：回退本地精选或缓存。

### 7.2 国家目录

当前已接入：

- 请求 `/json/countries`。
- 按电台数量排序。
- 缓存约 24 小时。
- 使用中文国家/地区名展示。
- 内置重点国家作为兜底。
- 支持国家搜索。

当前国家搜索支持：

- 中文名：`日本`、`美国`、`中国`
- 英文名：`Singapore`
- 国家代码：`JP`、`US`、`CN`

### 7.3 电台目录查询

地图页根据当前范围查询 Radio-Browser：

- 国家全部：使用 `countrycode`。
- 城市/地区：使用 `countrycode + state`。
- 搜索电台名：使用 `name`。
- 搜索标签/流派：使用 `tag`。
- 搜索地区：使用 `state`。

Flutter 合体包中，搜索框已采用发现式查询：同一关键词会合并尝试电台名、tag 和地区/state 三类查询，减少用户理解底层字段的负担。

筛选规则：

- `lastcheckok=1`
- 必须有 `url_resolved` 或 `url`
- codec 不能是 `UNKNOWN`
- 优先播放 `url_resolved`
- 使用 `stationuuid` 作为唯一键

质量字段保留：

- `stationuuid`
- `codec`
- `bitrate`
- `votes`
- `clickcount`
- `geo_lat`
- `geo_long`
- `homepage`
- `favicon`

### 7.4 分页加载

当前已从固定 48 条升级为分页加载：

- 每页请求 `limit=48`。
- 下一页使用 `offset`。
- 抽屉默认展示 12 条。
- 点击“加载更多”先展开当前已同步结果。
- 当前页展开完后继续请求下一页。
- 分页 offset 只在请求成功后提交；加载更多失败时保留当前列表和当前页码，用户重试不能跳页。
- 国家、城市、定位和搜索请求使用当前条件快照和请求序号保护；快速切换时晚返回的旧响应不得覆盖新国家/新城市列表。
- 电台列表默认展示“播放”动作，不在用户点击前把远端结果标记为“播放中”。
- 地图视觉覆盖层不得拦截手势；地图必须可拖拽、缩放并支持 marker 点击，抽屉上滑不应让地图失去响应。

示例验证：

- 日本目录初次同步约 43 条可用结果。
- 展开后继续触发 `offset=48`。
- 下一页同步后日本目录扩展到约 82 条。

### 7.5 缓存

当前缓存策略：

- 国家目录缓存约 24 小时。
- 每个国家/地区/搜索词的电台结果独立缓存。
- 缓存命中时先展示缓存，再后台刷新公共目录。

这样可以避免每次进入地图都依赖实时公共 API。

## 8. 地图发现页功能说明

### 8.1 页面结构

地图页由三层组成：

- 地图背景：当前 V1 原型按地区选择兜底瓦片；中国大陆使用高德 Web，海外使用 OSM DE 主源 + OSM HOT fallback，避免高德海外空白瓦片遮住底图；瓦片即时显示并回收错误瓦片，避免公共瓦片短时失败时整屏空白。
- 少量电台 marker：仅展示少量，避免地图变花。
- 单一底部抽屉：承载国家/城市、电台列表、搜索、筛选和播放。

页面顶部：

- 返回按钮。
- 当前国家/地区标题。
- 地球背面电台按钮。
- 重新定位按钮。

地图中部：

- 定位点。
- 当前定位状态。
- 目录来源状态。
- 地图电台 marker：点击后出现轻量“已锁定地图电台”信号卡，可在卡片上点“收听”；同时底部抽屉将该电台置顶并高亮，方便用户继续从目录中确认。

底部抽屉：

- 电台 Tab。
- 位置 Tab。
- 搜索框。
- 类型/情绪筛选。
- 电台列表。
- 当前选中电台卡。
- 抽屉默认约 38% 屏幕高度，保留地图空间感；上滑后接近全屏，搜索、筛选和电台列表采用更紧凑的目录密度。

### 8.2 定位逻辑

进入地图页时：

1. 尝试使用原生定位或浏览器 geolocation 获取经纬度。
2. 获取经纬度成功后立刻移动地图 camera 到当前位置，并设置“当前位置附近”状态。
3. 异步使用 Nominatim 反向地理编码获取城市和国家码；反查失败时使用经纬度粗略推断国家，不阻断地图移动。
4. 定位成功后优先用 `geo_lat / geo_long / geo_distance` 查询 Radio-Browser 附近电台。
5. 附近结果不足时，补当前城市/地区或国家目录，避免附近页空白。
6. 定位失败时回退当前国家或默认城市目录，不显示阻断错误；地图继续展示可用电台 marker，用户可拖拽、缩放和手动选择国家/城市。

权限失败不阻断播放。用户仍可手动选择国家和城市。

V1 首页调谐策略：

- 首页调谐条定位为“可用电台选择器”，优先让用户快速切到真的能播放的频道。
- 对带 FM 数字的电台，按频率数值排序，避免 98.5 / 100.3 的位置感错乱。
- 切换底部推荐频道、地图点播或全局搜索点播后，调谐条必须立即同步到当前电台所在国家/地区和候选位置。
- 传统收音机式 100.3 -> 100.2 -> 100.1 空频扫描保留为后续二级“专业调谐 / 机械调谐”能力，不放在首页主链路里。

### 8.3 位置切换

位置 Tab 中包含：

- 国家列表。
- 当前国家下的城市/地区范围。
- `全部` 国家级目录入口。
- 重点国家的常用城市/地区入口，例如新加坡、Toa Payoh、东京、大阪、California、London、北京、上海等。
- Radio-Browser `/json/states/<country>/` 返回的公共地区/州/城市目录，例如新加坡的 Singapore / Toa Payoh、美国的 California / New York、日本的 tokyo 等。
- 独立城市/州/地区搜索框：输入关键词时过滤内置重点城市，并请求 `/json/states/<country>/<filter>` 获取 Radio-Browser 地区目录结果。

重点交互：

- 切换国家后，默认进入该国家 `全部`。
- 切换城市/地区或公共地区目录项后，用更精细的 `state` 查询。
- 搜索城市时不混入“全部电台”等无关入口，优先让用户直接选择匹配城市/地区。
- 地图中心、标题、电台列表、选中卡同步更新。

### 8.4 电台搜索

电台 Tab 中的搜索框支持：

- 电台名搜索。
- 流派/标签搜索。
- 地区搜索。

搜索结果为空时：

- 展示轻量空状态。
- 不混入无关热门电台。
- 用户可清空搜索回到当前国家/地区目录。

### 8.5 筛选

当前原型支持两组筛选：

- 类型：全部、流行、独立、谈话。
- 情绪：全部、本地、专注、夜间。

当前筛选基于 Radio-Browser 的 name/tags/language 做轻量归类。正式版可进一步改为：

Flutter 合体包先提供轻量快捷筛选 chip：

- `jazz`
- `news`
- `classical`
- `electronic`
- `talk`
- `pop`

- 直接使用 Radio-Browser tag。
- 支持多选 tag。
- 增加音乐、新闻、体育、古典、爵士、电子等更明确分类。

### 8.6 地图 Provider 与瓦片缓存

当前 Flutter 原型使用 `flutter_map` 承载地图，`Cp17MapProvider` 负责选择 provider。V1 阶段按地区选择兜底：`CN` 使用高德 Web；海外使用 OSM DE 主源，并以 OSM HOT 作为 fallback。地图页进入时先展示本地精选兜底列表，Radio-Browser 远端目录返回后再替换为公共目录，优先保证用户不面对空白等待。

缓存策略审核结论：

- 不直接把 `cached_network_image` 塞进地图瓦片层。它适合普通图片组件，不适合替代 `flutter_map` 的 tile provider 生命周期、并发加载、错误回收和坐标缓存策略。
- V1.1 / V2 如需瓦片缓存，应在 `Cp17MapProvider` 后面接专用 cached `TileProvider`、tile cache manager 或正式地图 SDK 自带缓存能力。
- 中国大陆正式版优先百度 / 高德 provider，海外优先 Google / Mapbox / OSM provider；坐标转换在 provider 层处理，不侵入地图页 UI。
- 公共瓦片出现海面或极地区域色块边界时，V1 可接受轻微视觉瑕疵，但不得遮挡 marker、抽屉、标题或播放操作。

### 8.7 地球背面电台

该能力用于把地图页从“找电台工具”升级为“地球收听仪”，服务传播话术：“我在 App 里加了个功能，可以听到地球正对面那个物理盲区的当地广播”。

交互入口：

- 地图页顶部提供 `地球背面` 圆形按钮。
- 点击后优先获取本机当前位置；定位不可用时使用当前地图中心作为起点，避免功能卡死。
- 计算对跖点：`lat = -lat`，`lng = lng >= 0 ? lng - 180 : lng + 180`。
- 触发后采用 600-900ms 的“精密仪器数字跳变”转场：显示 `ANTIPODE CALIBRATION`、起点坐标、背面坐标和 `约 20,015 km`，而不是完整 3D 地球翻转。
- 地图 camera 移动到对跖点，标题显示“地球背面电台”，地图 marker 标出“起点”和“背面”。

数据查询：

- 使用 Radio-Browser `geo_lat / geo_long / geo_distance` 查询对跖点附近电台。
- 半径按 `300km -> 800km -> 1500km -> 3000km -> 6000km` 逐步扩大。
- 不强制按当前国家过滤，避免对跖点落海或跨国时查不到结果。
- 若仍无结果，回退全球热门目录，并在来源中显示“全球热门兜底”，不能误导为精确附近电台。
- 对跖点扩半径到 1500km 以上时，UI 可显示“你的背面是一片汪洋，已定位最近的大陆边缘广播”，把海洋陷阱转化为可理解的情绪反馈。

结果排序：

- Radio-Browser 返回结果先按本地质量分排序。
- 质量分参考 `lastcheckok`、`votes`、`clickcount`、`bitrate`、codec 和是否带坐标。
- 本机已标记不可用的 stream URL 必须降权，降低用户连续点到坏源的概率。

分享元数据：

- 从地球背面模式点播的电台会携带 `discoveryMode=antipode`、对跖点坐标、命中半径和分享故事文案。
- 声音明信片分享文案优先使用“我正在用 Void Radio 收听地球另一面的当地广播”。

## 9. 播放功能说明

### 9.1 当前播放链路

当前推荐 Flutter 合体包使用 `audio_service + just_audio + audio_session` 播放直播流；React/Vite 原型仍保留浏览器 `<audio>` 作为历史高保真验证壳。

播放流程：

1. 用户点击播放按钮或地图电台。
2. 设置当前电台。
3. 如果有 `streamUrl`，加载音频源。
4. 状态进入“连接直播流”。
5. 播放成功后进入 `LIVE 直播中`。
6. 播放失败时进入“点击播放”或“播放失败”。

当前 Flutter 合体包已对播放入口做幂等处理：地图点播或快切电台时会先设置媒体项，再显式触发 `play()`；播放失败会释放本次 source-loaded 状态，方便用户再次重试或切换电台。

### 9.2 地图点播

从地图页点击电台行或选中卡“收听”：

- 立即选中该 Radio-Browser 电台。
- 关闭地图页。
- 回到主页。
- 主屏进入连接/播放/明确失败状态。
- 不要求用户再次点击播放。
- 该电台写入本地首页电台库，下次打开仍可在底部快切轨中选择。

最近 API35 compact AVD 验证中，地图点播 `WARNA 942` 可返回主页并进入 `NET / LIVE` 或明确 `播放失败`；部分 Radio-Browser 电台仍可能因公共流不稳定而连接较慢或失败，此时必须显示连接中或失败提示，不得静默停留在暂停。

### 9.2.1 本地电台库

Flutter 合体包已新增轻量本地电台库：

- 出厂精选仍由代码 seed data 提供，不重复写入本地存储。
- 用户从 Radio-Browser 点播的电台写入 `shared_preferences`。
- 收藏 ID、喜欢 ID、最近选中的电台 ID 分开保存。
- 首页顺序单独保存。
- 被移除的出厂精选电台记录为隐藏项。
- 重新打开 App 后合并出厂精选和用户新增电台。
- 底部快切轨用小红星 / 小红心提示已收藏或已喜欢。
- 选项 -> 首页电台库中支持拖拽排序、移除首页电台和手动添加自定义 stream URL。
- 选项 -> 首页电台库中支持标记当前主源不可用、添加备用流 URL。
- 坏源和备用流均保存在手机本地，不上传、不做社区审核。

尚未实现：远端坏源报告、社区审核后的公共备用流分发、自动健康检查服务。

### 9.3 播放失败自动候选

Radio-Browser 中存在坏源、地区限制、跨域问题或 WebView 不兼容流。为降低用户挫败感，当前已加入本地坏源和失败兜底：

- 用户可在“首页电台库”中把某个电台主源标记为不可用。
- 用户可为该电台添加一个或多个备用流 URL。
- 播放前会过滤本机已标记不可用的 URL。
- 如果主源已标记坏且存在备用流，系统会把备用流提升为本次播放源。
- 当前源播放失败后，`AudioHandler` 会继续尝试同一电台的备用候选。
- 运行中播放流报错时，`AudioHandler` 也会尝试后续备用流候选，而不是只停在 error 状态。
- 备用候选切换有互斥保护；播放器 error、completed 或用户操作同时触发时，只允许一个候选推进流程，避免重复跳源或状态回写打架。
- 触发备用候选时，`playbackNotice` 会同步到主屏状态文案，并用浮动 SnackBar 给出轻提示，例如“当前源不可用，正在尝试备用流 2/3”。
- 触发切台、备用候选或直播流 loading 时，会播放本地 `assets/audio/void_tune_noise.wav` 的低音量“虚空寻台”底噪，模拟仪器从电波中捕捉信号；该底噪由独立 `just_audio` 播放器承载，不进入 media session，不改变主播放状态。
- 主流进入 ready、用户暂停/停止、候选耗尽或切换媒体项时，底噪必须立即停止并回到起点；它只能是 1 秒左右的过渡，不允许循环常驻或盖过真实电台。
- 候选耗尽后才显示明确失败或点击播放状态。

审核结论：

- 自动尝试备用源必须保留，并保持轻提示可见，避免用户误以为 App 无感串台。
- V1 仍把“标记主源不可用 / 添加备用流”收在“首页电台库”中，避免播放失败 toast 变成重操作入口。
- 远端坏源报告、社区审核后的公共备用流分发、自动健康检查服务不进入 V1，留到后续远端能力阶段。

- 默认分享开场白为“我在 Void Radio 发现了一个可以直接收听的网络电台”，地球背面等特殊模式可通过 `storyLabel` 覆盖；情绪短句和播放链接必须保留。
- 支持微信、WhatsApp、系统分享目标。

公网落地页策略：

- V1.1 新增静态页面目录：`23_原型管理/cp17_listen_landing/`。
- 不需要先购买域名；可先部署到 Cloudflare Pages、Vercel 或 GitHub Pages，得到 HTTPS 地址。
- 打包时通过 `--dart-define=CP17_LISTEN_BASE_URL=https://<pages-url>/` 注入基础地址。
- 正式域名建议等传播玩法验证后再购买，并配置 Android App Links / iOS Universal Links；如果复用 `feedar.cc`，优先使用 `listen.feedar.cc` 承载声音明信片，`radio.feedar.cc` 后续承载官网/下载页，不直接切主域名根路径，避免影响现有交易系统。
- 页面通过 URL 参数读取 `station / place / freq / stream / now / mode / story / lat / lng`，渲染 Void Radio 声音卡片和原生 `<audio controls>`。
- 部分公共电台流可能因跨域、地区限制、HTTP 混用或移动浏览器策略无法在网页内直接播放，页面必须保留“打开原始直播流”兜底。

明信片内容建议：

- `SIGNAL INTERCEPTED` 信号截获标题和唯一红色信号点。
- 白底热敏票据视觉：旧纸白背景、褪色墨水、虚线走纸、细纸张噪点和极细静态波形。
- 数据区使用等宽字体，标签和英文参数大写化；中文 human note 使用衬线体或更有纸张温度的字体，避免整张图像服务器日志。
- UTC 时间戳、协议类型、码率估算、信号源坐标、本机/起点坐标、跨越距离、本地/信号源时间。
- 截获载荷区：频率/NET、电台名称、当前曲目或节目 fallback。
- 底部低噪音中文 human note：固定第一句“一台安静的仪器，在这个坐标捕获了这段波形。”，第二句从内置情绪短句池稳定轮换，例如“我的深夜，你的清晨。”或“世界另一侧的日常，刚好穿过我的房间。”
- 如果没有真实本机坐标，不伪造坐标，显示 `DEVICE REDACTED` 或直播地点兜底。

2026-07-07 视觉口径更新：声音明信片不再使用浅色风景明信片、普通音乐卡片，也不再使用过度黑客化的黑底终端 / 服务器日志风。默认模板改为“白底热敏票据”方向：旧纸白背景、褪色墨水、唯一红色信号点、虚线走纸、极细静态波形和衬线体中文旁白，让分享图更像一台真实桌面仪器吐出的物理凭证，而不是屏幕截图或控制台日志。

## 17. 当前限制

- 当前 Flutter 合体包已作为 V1.1-dev 主工程进入私有代码仓库；早期 React / Capacitor 原型仅保留为视觉和交互参考。
- 当前后台播放已有架构并已通过 moto G55 / Android 16 真机 30 分钟熄屏不断流门禁；锁屏/通知栏控制已有架构，媒体键暂停/继续 smoke 通过，但锁屏样式、通知栏视觉和真实蓝牙按钮仍需完整验收。

- 当前地图位置页已接入独立城市/州/地区搜索，但 Radio-Browser 地区目录本身并非严格城市数据库；部分城市可能没有 state 目录，需要回退国家目录或电台搜索。

- 当前公共地图和反向地理编码依赖外部服务，正式版需评估限流与可用性；V1 已改为中国高德 Web、海外 OSM DE/HOT 的分区兜底，但正式地图 provider 仍需进一步统一瓦片风格、坐标体系和缓存策略。缓存应在 TileProvider / 地图 provider 层实现，不直接用 `cached_network_image` 替代瓦片层。
- 当前声音明信片已接入 Flutter 主工程；moto G55 已验证系统分享面板可显示微信、WhatsApp、微信发送给朋友、朋友圈、微信收藏和企业微信。实测微信图片分享只发送图片、不发送附带文本，因此 V1.1 新增“分享播放链接”纯文本入口；已向微信联系人“马天正”发送图片和纯文本链接，接收端点击链接并播放仍需最后一步人工验收。

## 21. V2.0 私人微电台实施状态（2026-07-13）

### 用户目标

用户可以把自己的群晖 / QNAP / 通用 NAS SMB、WebDAV 或 AList WebDAV 音乐目录绑定为 `NET · PRIVATE STATION`，从设置页测试连接、扫描音频并直接收听。回到首页后仍保持 Void Radio 的频率仪表盘和 Now Playing，不出现文件管理器式主界面。

### 已实现范围

- 设置 -> 收听新增“私人微电台”，支持 NAS SMB、WebDAV 和 AList 三类连接。
- 私人微电台作为设置的子页面打开；返回按钮或系统侧滑返回必须回到原设置面板，不得越级返回首页。
- 非秘密配置本地保存；Android 密码 / Token 由 Keystore 生成 AES-GCM 密钥后加密保存。
- WebDAV 使用 `PROPFIND Depth: 1`，识别 MP3、AAC、M4A、FLAC、OGG、OPUS、WAV、目录、`.lrc` 和 JPG / PNG / WEBP 封面。
- 同名 `.lrc` 优先关联到曲目，`cover / folder / front` 作为目录封面候选。
- 扫描结果可选择任意曲目播放；整个结果作为私人媒体队列进入现有 `audio_service + just_audio`，支持上一曲、下一曲和自然连播。
- 私人曲目切换后同步首页、通知栏媒体项和现有 Now Playing；同目录 `.lrc` 使用内存凭据读取，在线歌词不抢占本地歌词。
- 私人曲目不写入普通首页电台快照，避免重启后出现缺少凭据的失效 URL；连接和目录仍由私人微电台页管理。
- NAS 使用 `dart_smb2 / libsmb2 6.1.0`，支持 SMB2/3，禁止 SMB1；连接可选择强制 SMB3 加密。
- NAS 目录最多递归 8 层 / 2000 个资源；音频由 `127.0.0.1` 随机令牌 Range 网关按需读取，不整首下载到内存或磁盘。
- NAS 地址只允许局域网、`.local`、单标签主机和 Tailscale 网段，不支持公网直接暴露 SMB 445。

### 安全约束

- URL 不允许内嵌 `user:password@host` 或查询 Token；公网服务必须使用 HTTPS，HTTP 只允许 localhost、`.local` 和 RFC1918 局域网地址。
- 密码 / Token 不进入 SharedPreferences 明文、媒体元数据、系统分享、日志、测试夹具和 Git。
- Android 原生保险箱错误只返回统一错误，不回传加密内容或原始异常详情。
- SMB 本机播放 URL 不包含 NAS 地址、账号、密码或远端路径，只暴露会话期随机令牌。
