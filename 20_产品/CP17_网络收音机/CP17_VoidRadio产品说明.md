# Void Radio 产品说明

## 1. 产品概述

**Void Radio 是一台安静扫描世界电台的数字仪器。**

它不以“收录最多电台”为目标，而是把全球网络广播重新组织成一种克制、可触摸、有空间感的收听体验：用户可以从少量精选信号开始，通过机械调谐、地图发现、地球背面和独立信号逐步探索世界，并把某一刻捕获的声音分享给想分享的人。

## 3. 目标用户

- 喜欢独立电台、城市声音、音乐文化和世界旅行感的人。
- 对普通电台 App 的密集列表、广告和廉价界面感到疲倦的人。
- 希望把手机横放在桌面或床头，作为长期播放仪器使用的人。
- 喜欢 Teenage Engineering、机械表盘、VFD、桌面时钟等克制工业设计的人。
- 后续希望连接个人 NAS、WebDAV 或 AList，建立私人音乐电台的人。

## 4. 核心价值

### 4.1 从“查目录”变为“捕获信号”

首页只保留少量精选和用户相关电台，不把海量公共目录直接倾倒给用户。调谐尺、轻触反馈和短暂寻台噪音，让切台更接近真实仪器，而不是普通列表点击。

### 4.2 从“国家列表”变为“世界探索”

地图页用于观察不同国家和城市的广播分布。用户可以定位附近、浏览地图信号、进入地球背面，或在对跖点落入海洋时继续寻找最近大陆边缘的广播。

### 4.3 从“分享链接”变为“分享一次捕获”

声音明信片记录电台、地点、时间、经纬度和距离。分享落地页无需安装即可试听；V1.2 开始支持从网页回到 App，并且不会在用户未确认时自动播放第三方直播流。

### 4.4 从“网盘播放器”变为“私人微电台”

V2.0 开发版已经可以连接 WebDAV、AList WebDAV 和群晖 / QNAP 等 SMB2/3 NAS，把个人音乐目录绑定为 `NET · PRIVATE STATION`。私人曲目继续复用首页、后台媒体队列、Now Playing 和同目录 `.lrc`，不把产品改造成文件管理器。正式发布前仍需用真实存储账号完成端到端兼容性和长时播放验证。

## 5. 主要功能

### 5.1 首页仪器

- 当前频率或 `NET` 信号显示。
- 真实播放、暂停、上一台和下一台。
- 当前电台、当前曲目和连接状态。
- 收藏、喜欢、床头钟、地图和独立信号快捷入口。
- 当前地区手动调谐尺。
- 最多 8 个个性化预设：当前电台、同地区收藏/喜欢和地区候选优先。

### 5.2 收藏与电台库

- 首页星标用于快速收藏或取消收藏当前电台。
- 独立收藏页展示全部收藏，支持名称、地区、语言和频率搜索。
- 当前播放电台在收藏页优先显示，并带播放状态标记。
- 点击收藏项直接切台；取消收藏不会删除电台源。
- 首页电台库继续负责排序、导入、自定义 URL、坏源和备用流管理。

### 5.3 世界发现

- Radio-Browser 国家、地区、流派和关键词搜索。
- 地图 marker、低缩放聚合和单台选择。
- 当前定位和附近电台。
- 地球背面对跖点计算、阶梯半径搜索和海洋兜底。
- 独立、社区、学院和自由格式电台策展。
- 按华语、英语、日语、德语、法语和西语等语种发现信号。

### 5.4 Now Playing

- 二级沉浸式正在播放页面。
- 当前曲目、封面占位和播放控制。
- 真实 ICY / 官方元数据驱动的当前曲目。
- LRCLIB 开源歌词 Beta，MusicBrainz 仅用于名称别名匹配。
- 歌词只在 Now Playing 展示，不侵占首页。

### 5.5 桌面与睡眠

- 横屏简洁仪器布局。
- 经典翻页床头钟。
- 睡眠定时。
- 后台播放、媒体通知和系统媒体键控制。

### 5.6 分享

- 本地生成声音明信片。
- 微信和系统分享。
- 公网落地页直接试听主源与备用源。
- `voidradio://listen` App 回流，导入后由用户点击播放。

### 5.7 私人微电台（V2 开发版）

- 支持 WebDAV、AList WebDAV 与 NAS SMB2/3，不支持不安全的 SMB1。
- Android 密码或 Token 使用 Keystore + AES-GCM 加密保存。
- SMB 仅允许局域网、Tailscale、`.local` 和本地主机，不开放公网 445。
- 支持完整目录曲目列表、上一曲、下一曲、自然连播和后台媒体队列。
- 支持 MP3、AAC、M4A、FLAC、OGG、OPUS、WAV，以及同目录 `.lrc` 和常见封面。
- SMB 音频经只监听 `127.0.0.1` 的随机令牌 Range 网关按需读取，不整首下载到内存或磁盘。
- 私人曲目不会写入普通电台库，也不会把凭据带入媒体信息、日志或分享链接。

## 6. 信息架构

1. **首页：** 当前信号、轻量操作、调谐和少量个性化预设。
2. **Now Playing：** 曲目、封面、歌词和沉浸控制。
3. **收藏电台：** 大量收藏的搜索、查看和切台。
4. **地图发现：** 国家、地区、附近和地球背面。
5. **设置：** 电台库、搜索、语言信号、独立信号、仪器设置和分享。
6. **私人微电台：** 连接、扫描和管理私有音乐源，但播放仍回到统一首页与 Now Playing；从该页返回时恢复原设置面板。

## 7. 差异化

| 普通网络电台 App | Void Radio |
|---|---|
| 以海量目录和搜索为中心 | 以少量精选和探索过程为中心 |
| Material 列表和功能堆叠 | 安静仪器、留白和物理反馈 |
| 点击列表立即播放 | 调谐、连接反馈、显式播放状态 |
| 国家或标签筛选 | 地图、地球背面、当地时间和距离叙事 |
| 分享普通 URL | 声音明信片、网页试听和 App 回流 |
| 本地文件播放器 | V2 私人微电台表达 |

## 8. 隐私与合规

- 默认不要求账号，不建立用户画像。
- 收藏、喜欢、排序、坏源和设置优先保存在设备本地。
- 定位仅用于附近电台和地理探索，拒绝权限后仍可手动浏览。
- 不使用网易云、QQ 音乐等未授权灰色歌词接口。
- 第三方公开直播流可能随时失效，App 通过备用源、健康降权和明确失败状态处理，不伪装内容授权关系。
- V2 接入私人存储时，凭据必须安全保存在系统安全存储中，不写入普通偏好、日志或分享链接。
- V2 SMB 播放引入 `dart_smb2` 与 LGPL-2.1-or-later 的 `libsmb2`；商业发布前必须完成人工许可复核和第三方声明。

### 9.1 推荐发布顺序

1. 先以 `V1.1.3 RC2` 完成签名 AAB、Play Console 和封闭测试，形成第一个可公开安装版本。
2. 收口 V1.2 未完成地图与回流门禁，冻结为 V1.2 RC 后再发布。
3. 决定 V1.3 是否保留为独立版本；若保留，先建立正式范围、分支和台账，不让 V2 依赖一个不存在的 RC。
4. 将 V2 私人微电台重放到最终稳定公开基线，完成真实存储 L3 与 LGPL 合规后再冻结 V2 RC。

## 10. 商业化方向

- 基础收听、经典翻页钟和必要的播放能力保持可用。
- Premium 可承载私人微电台、多连接源、高级时钟主题、录音/剪辑和更完整的车载能力。
- 商业化不能通过广告墙、推荐信息流或强制账号破坏首页的安静仪器定位。

## 11. 对外简短介绍

Void Radio 是一台安静扫描世界电台的数字仪器。转动调谐尺，浏览地图上的城市信号，或去听地球另一面的当地广播；也可以把自己的 NAS 与 WebDAV 音乐目录接成一座私人微电台。收藏你愿意再次回去的频率，把某一刻捕获的声音分享给想分享的人。
