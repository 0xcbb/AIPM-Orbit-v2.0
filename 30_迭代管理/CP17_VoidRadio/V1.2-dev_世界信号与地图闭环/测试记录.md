## 页面验证

- GitHub Pages 脚本语法与回流标记静态检查通过。
- V1.2 落地页分支 `codex/v1-2-app-return` 通过本机 HTTP 页面验证：电台、地区、频率、曲目和经纬度参数正确渲染；自动生成的 `voidradio://listen` 完整保留 `station / place / freq / stream / fallback / now / mode / lat / lng`。
- 390 x 844 移动视口实测 `scrollWidth=390`，主卡宽 346px、播放按钮宽 300px，无横向溢出；自定义视口的全页截图出现缩放异常，但 DOM 布局指标正常，判定为测试工具截图问题。
- 点击“立即收听”会显式调用 `audio.play()` 并在失败后切换备用流；UFM AAC / MP3 主备流通过独立网络请求持续返回音频数据，但 Codex 内置浏览器媒体层未能播放，真实手机 Chrome / Safari 仍为 **待人工确认**。
- 线上 `listen.feedar.cc` 合并前仍需验证 HTTPS 页面、真实浏览器试听和 App 回流。
